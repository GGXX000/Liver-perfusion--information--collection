# 🏥 医院临床实验数据采集系统

---

## 📍 1. 项目背景与目标

### 1.1 背景说明

医院在进行临床实验研究时，需要采集大量的实验数据（例如血气分析、检测报告、影像文件等）。目前多依赖人工记录或Excel表格，数据分散、不统一、不安全。本项目旨在建立一个基于 Web 的数据采集系统，使医生能够：

- 在网页端安全录入和上传实验数据；
- 系统后端自动存储并管理这些数据；
- 后续可扩展支持影像、文档、AI分析模块。

### 1.2 项目目标

1. 建立可远程访问的实验数据采集平台。
2. 实现前后端分离架构，支持灵活扩展。
3. 数据集中化存储（结构化 + 非结构化）。
4. 支持用户身份认证、安全传输。
5. 采用 Python 技术栈，保证团队统一开发语言。

---

## ⚙️ 2. 系统总体架构设计

### 2.1 技术栈总览

| 层级               | 技术                | 说明                                           |
| ------------------ | ------------------- | ---------------------------------------------- |
| 前端层             | Vue3 + Element Plus | 医生网页端交互界面                             |
| 后端层             | FastAPI             | 提供 RESTful API、业务逻辑、认证授权           |
| 数据库层           | SQLite              | 文本，数字，图片路径保存在db中，大文件放在硬盘 |
| 认证与安全（暂定） | OAuth2 + JWT        | 用户认证与访问控制                             |
| 部署与访问         | Cpolar              | 支持公网安全访问                               |
